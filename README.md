# “隐盾” 批量文档敏感信息智能脱敏系统 (Qt_File_Redaction)

一款基于 C++17 与 Qt6 开发的跨平台、高性能、多格式文档脱敏桌面工具。旨在为政府、高校、医疗机构及企业提供轻量级、格式无损的数据安全合规解决方案。

## 核心特性 (Features)

*   **多格式深度支持**：支持 `.txt`, `.csv`, `.docx`, `.xlsx`, `.doc`, `.xls`, `.html` 等 10 余种主流文档格式。
*   **原文件格式完美保留**：摒弃传统的“提取纯文本”逻辑，**自研 OpenXML 解析器**，通过解包 ZIP 与修改底层 XML 节点，实现脱敏后 Word/Excel 的表格、图片、页眉页脚无损保留。
*   **高准确率双层校验**：采用“正则快速定位 + 算法深度校验”架构，集成**身份证加权校验码**、**银行卡 Luhn 算法**及工信部手机号段白名单，误报率极低。
*   **多地区规则隔离**：支持中国大陆及港澳台地区的专属证件、手机号规则，一键下拉切换，精准匹配。
*   **国密 SM3 匿名化**：内置国密 SM3 哈希算法，支持将姓名、地址等非结构化信息替换为不可逆的 16 位哈希值，满足“去标识化”合规要求。
*   **自适应流式处理**：小文件内存读入，大文件（>50MB）采用 64KB 分块流式读取，内存占用恒定于 KB 级，无惧大文件内存溢出。
*   **防篡改自定义规则**：所见即所得的自定义模板，强制非星号位置字符一致性，从源头杜绝数据伪造。

## 技术栈 (Tech Stack)

*   **开发语言**：C++17
*   **GUI 框架**：Qt 6.11 (Widgets)
*   **构建工具**：CMake / MSBuild
*   **第三方库**：minizip (ZIP 解析), pugixml (XML 解析)
*   **外部引擎**：pandoc (多格式转换), xdoc2txt (旧版 Office 解析)

## 系统架构 (Architecture)

1.  **扫描层**：多级目录递归遍历，过滤无关文件。
2.  **转换层**：三引擎架构（自研 OpenXML 解析器 + xdoc2txt + pandoc），按需分配。
3.  **脱敏层**：多线程并发处理，正则匹配 + 算法校验 + SM3 匿名化。
4.  **输出层**：原子写入（防损坏），保留原始目录树结构。

## 性能表现 (Performance)

*   得益于 C++ 底层优化与多线程调度，处理 1.3MB 含数万单元格的 Excel 文件，耗时从初始版本的 15 秒优化至 **1 秒内**。
*   流式分块处理超大文本，内存占用平稳恒定，不随文件体积暴涨。

## 编译与运行 (Build & Run)

> 注意：由于涉及外部依赖，请确保环境配置正确。

1. 克隆本仓库。
2. 使用 Visual Studio 2022 打开 `Qt_File_Redaction.slnx`。
3. 确保已安装 Qt 6.11+ 并配置好 Qt VS Tools。
4. 将外部转换工具（`pandoc.exe`, `xdoc2txt.exe`）放入可执行文件同级目录的 `tools` 文件夹下。
5. 编译生成。
